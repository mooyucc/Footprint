# Snap2Store Export

Format: JPG (no alpha), ready for App Store Connect.

Folders:
- iphone-6.9/ → iPhone 6.9″ portrait 1320×2868
- iphone-6.5/ → iPhone 6.5″ portrait 1284×2778
- ipad-13/ → iPad 13″ landscape 2752×2064
- ipad-13-portrait/ → iPad 13″ portrait 2064×2752
- mac-16/ → Mac 16:10 2560×1600
- metadata/zh-Hans.txt、metadata/en.txt → paste into Connect localization fields

Note: iPhone 6.9″ and 6.5″ share the same layout; upload each folder to the matching Connect display slot. iPad landscape, iPad portrait, and Mac are independent layouts. Portrait iPad does not rotate the screenshot; only the frame cutout adapts.
